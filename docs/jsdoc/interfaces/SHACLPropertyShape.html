resolveLanguage

• Optional resolveLanguage: string

AD4M-specific: sole selector of storage mode:

  • unset → deterministic typed literal (fast POS-index path, the default for a plain @Property()).
  • "literal" → signed envelope on the built-in literal language (per-value provenance, e.g. Flux message bodies).
  • <custom address> → expression_create on that custom language.
