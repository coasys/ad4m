# AD4M

AD4M (Agent-centric Distributed Application Meta-ontology) is a runtime that runs once per person, on their own machine or on a host they choose. It holds that person's keys and identity (a DID), stores their data in signed knowledge graphs called perspectives, and shares those graphs with other people as neighbourhoods. Apps do not run a server; they connect to the user's executor over a local RPC port and read and write typed data through models. AI agents connect to the same executor over MCP and work with the same data, described by the same schemas. Protocols and storage systems are attached underneath as languages, so one graph can point at data living anywhere.

```
  Apps (web, desktop, mobile)     AI agents (MCP clients)
            │  RPC :12000                │  MCP :3001
            └──────────────┬─────────────┘
                 one executor per agent
      keys · perspectives · neighbourhoods · models · flows
            ┌──────────────┴─────────────┐
       Languages: literal, p2p sync (Holochain), HTTP, custom
```
